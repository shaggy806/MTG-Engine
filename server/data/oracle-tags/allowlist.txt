# Scryfall Tagger oracle tags the card replacer compares cards on.
#
# One tag slug per line; `#` starts a comment. Only tags that describe what a
# card DOES belong here: its role in a deck. Tagger also carries tags about a
# card's name, art, printing history, set design or rules trivia
# ("alliteration", "cycle-*", "typal-*", "type-errata", "fun-ruling"), and those
# are left out on purpose: they're rare, so they'd dominate a similarity score
# that weights rare tags heavily, and they say nothing about what a stand-in
# should do.
#
# A search on a parent tag also returns cards tagged with its children
# (oracletag:removal includes everything under removal-creature), so a broad
# tag and its specific children can both be listed: two cards that are both
# "removal" share a little, two that are both "removal-exile" share more. Rare
# tags count for more than common ones automatically (see card-replacer.ts).
#
# After editing: `npm run gen:oracle-tags -w server` rebuilds index.json from
# Scryfall's public search API (a few minutes; see the script). The script
# refuses a slug missing from Scryfall's public tag list
# (scryfall.com/docs/tagger-tags): search can't tell an unknown tag from one no
# card carries, and some tags shown on Tagger aren't searchable.
